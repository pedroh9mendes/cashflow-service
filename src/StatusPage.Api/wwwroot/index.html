Ações de instalação e carga

Executam processos reais na máquina local

Subir ambiente completo

Constrói e inicia todos os containers (SQL Server, RabbitMQ, APIs, observabilidade).

Este painel roda dentro de um container e não tem acesso ao Docker do host (Docker-in-Docker não está configurado neste projeto). Execute a partir de um terminal, na raiz do repositório:
docker compose up -d --build

Parar ambiente

Encerra todos os containers da stack, preservando os volumes de dados.

Mesma limitação acima — execute a partir de um terminal, na raiz do repositório:
docker compose down

Aplicar scripts de banco

Cria os bancos e tabelas (se necessário) e aplica a política de Row-Level Security em Lançamentos e Consolidado.

Popular dados de demonstração

Gera uma carteira de ~20 comerciantes com 30 dias de lançamentos via chamadas reais à API (pode levar alguns minutos).
